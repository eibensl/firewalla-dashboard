Firewalla Dashboard

    Type the Setup Code

    The setup code keeps anyone else on your network from changing your keys. A new one is made each time the dashboard starts.

    1. On your NAS, open Container Manager › Container, click the dashboard's container (its name ends in dashboard or is the one you chose), then Log.
    2. Find the line SETUP CODE for this start: XXXX-XXXX-XXXX. (It is also in the file config/setup_code.txt in the dashboard's folder, in File Station.)
    3. Type it below and click Continue.

    2. Router Access

    The dashboard reads your router through a locked-down connection. You type the router's SSH password once: the dashboard uses it a single time to set up its own key, then forgets it.

    Turn SSH On and Copy the Password

    1. Open the Firewalla app on your phone and tap your box.
    2. Tap Settings › Advanced › Configurations › SSH Console.
    3. Turn SSH on for the network this NAS is on. (On Gold and Purple, each network has its own switch.)
    4. Copy the password shown there. It changes whenever the router restarts; that is fine, the dashboard needs it only this once.
    5. Paste it below and click Connect.
    Picture to come: Firewalla app › Settings › Advanced › Configurations
    Picture to come: the SSH Console screen, with the switch per network and the password
    More (only for two NAS units working as a pair)
    The dashboard's key is accepted only from this NAS's address. With Synology High Availability, add the other unit's own address here.
    Setting up the router and checking it: this takes up to two minutes.

    What happens: the dashboard makes its own key, adds it on the router so it can only open a tunnel to a read-only filter (no commands, no other connections, only from this NAS), puts the read-only filter in place (or uses the one already there), and then tests all of it. Your other keys on the router are left alone. Keep SSH turned on in the app afterwards: if you turn it off, the dashboard stops until you turn it back on.

    5. Email Alerts (Optional)

    For the daily digest and alerts by email. The dashboard sends them from an email account of yours; they can go to any address.

    You need an "app password" from your email provider, not your normal email password. An app password is a separate password that your email provider (Google, Apple, Yahoo...) makes for one outside app, such as this dashboard. It only lets that app send email, and you can delete it in your email account at any time without changing your normal password.
    1. Your Google account needs 2-Step Verification turned on (Google Account › Security).
    2. Go to myaccount.google.com/apppasswords and sign in.
    3. Type "Firewalla Dashboard" as the app's name and click Create.
    4. Google shows a 16-letter app password. Copy it (the spaces don't matter).
    5. Fill in the boxes below and click Send Test Email.
    1. Your Apple Account needs two-factor authentication turned on.
    2. Go to account.apple.com and sign in.
    3. Open Sign-In and Security › App-Specific Passwords.
    4. Click +, name it "Firewalla Dashboard" and click Create.
    5. Apple shows an app-specific password like abcd-efgh-ijkl-mnop. Copy it.
    6. Fill in the boxes below (send from your full iCloud address, for example you@icloud.com) and click Send Test Email.
    1. Sign in at login.yahoo.com and open Account Info › Account Security.
    2. Click Generate app password (or Generate and manage app passwords).
    3. Name it "Firewalla Dashboard" and click Generate password.
    4. Yahoo shows a 16-letter app password. Copy it.
    5. Fill in the boxes below and click Send Test Email.
    1. In your email account's security settings, make an app password (it may be called "app-specific password" or "third-party app password") for "Firewalla Dashboard". Your provider's help pages explain where.
    2. Look up your provider's outgoing mail (SMTP) server and port (465 or 587) in its help pages.
    3. Fill in the boxes below and click Send Test Email.

    The menu names above come from each provider's help pages and may differ slightly on your screen.

    6. Ask Claude (Optional)

    The dashboard works fully without this step. With it, Claude (Anthropic's AI) explains what the dashboard finds, in plain words.

    What It Gives You

    • Ask buttons on findings (new connections, alarms, internet patterns, equipment problems): what happened, the likely reason, and which choice Claude would make.
    • Questions page: ask anything about your network, with follow-up questions.
    • Hourly check: new findings are explained ahead of time, so the answer is often already there.
    • Daily digest: a short summary of the day each morning (by email too, if you set up step 5).
    • Nightly review of the choices you made, flagging any that look out of date.

    Claude only reads the facts the dashboard hands it and writes text back. It can't change anything on your router or network, and it doesn't browse or run anything.

    What an API Key Is

    An API key lets an app (this dashboard) use Claude on your account, paid by use. It comes from the Claude Console, Anthropic's site for developers, which is separate from the claude.ai chat app.

    A Claude Pro or Max subscription doesn't cover this, and its sign-in can't be used here: Anthropic's terms don't allow other apps to use a subscription. The Console account is separate and paid by use.

    What It Costs

    • You pay only for what is used: each answer costs about 2 to 5 cents. (Anthropic charges by "tokens", pieces of words: for Claude Sonnet, $2 per million tokens read and $10 per million written.)
    • A home network typically costs about $5 to $20 a month.
    • Pick Claude Haiku below to pay about a twentieth of that ($0.10 per million tokens read, $0.50 written): its answers are shorter and less careful, but fine for everyday questions.
    • The dashboard's own daily limits (40 Ask Now questions and 24 hourly checks) keep it under about $60 a month even when used a lot.
    • You buy credit ahead (prepaid), and the monthly spend limit you set in the Console is a hard cap. When the credit or limit runs out, Claude simply stops answering; the rest of the dashboard carries on.
    • The dashboard's Settings page shows an estimate of each day's cost; the Console shows the real bill.

    How To Get Your Key

    1. Go to console.anthropic.com and make an account (or sign in).
    2. Open Billing, add a card and buy some credit, for example $10.
    3. Open Limits and set a monthly spend limit, for example $20. That is your safety cap.
    4. Open API Keys, click Create Key, name it "Dashboard" and copy it. It is shown only once: if you lose it, delete it and make a new one.
    5. Paste it below and click Save. The dashboard checks it with Anthropic (free) and tells you if it works.
    Picture to come: Claude Console › Limits, with a monthly spend limit
    Picture to come: Claude Console › API Keys › Create Key

    Keep the key private, like a password: it is saved only on this NAS. To stop Claude at any time, delete the key in the Console.
